# Backend ДуАТОМ

Единый backend: Flask API + SQLite + Telegram-бот в одном процессе.

JSON в `content/courses` и `content/questions` является каноническим источником учебных материалов. При старте backend синхронизирует его в SQLite по стабильным ключам. SQLite хранит пользователей, ID учебных сущностей, результаты входного теста и интересы, персональную учебную программу, попытки, прогресс уроков, атомкоины, магазин, покупки, подписки, ключи АТОМ+ и лимиты AI-чата. Telegram-бот использует ту же базу и ту же функцию генерации ключей АТОМ+.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python app.py
```

Flask API: `http://localhost:5001`.

Если в `.env` указан `TELEGRAM_BOT_TOKEN`, бот автоматически запускается вместе с Flask в отдельном потоке. Если токен пустой, веб-backend работает самостоятельно.

После новой регистрации пользователь проходит `/api/onboarding`: выбирает интересы и отвечает на 8 диагностических вопросов. Backend оценивает базовый уровень по предметам и сохраняет персональный порядок обучения.

Учебные endpoint-ы защищены сессией. Публично доступны только health/config, регистрация, вход/выход и проверка текущей сессии `/api/me`.

На production обязательно задайте собственный `FLASK_SECRET_KEY`; при HTTPS также включите `COOKIE_SECURE=true`.

## Формат насыщенной флешкарточки

Карточки в `content/courses/*.json` поддерживают не только `title`, `text` и `source`, но и структурированные учебные блоки:

- `details` — 2–4 ключевых пункта;
- `formula` — формула и расшифровка обозначений;
- `example` — разобранный числовой или смысловой пример;
- `code` — язык, код и ожидаемый результат выполнения;
- `takeaway` — короткая мысль для запоминания.

Поля необязательны по отдельности: например, исторической карточке не нужна искусственная формула, а карточкам Data Science можно добавлять `code`. Валидатор `python validate_content.py` дополнительно проверяет, что все карточки содержат ключевые пункты и итог, а в общей базе есть достаточное количество формул, примеров и кода.
