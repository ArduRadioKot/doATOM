# ДуАТОМ

Учебная веб-платформа в стиле Росатома: школьные предметы объясняются через мирные применения атомных технологий.

## Что есть в приложении

- публичный лендинг и обязательная авторизация перед учебными разделами;
- короткий онбординг сразу после регистрации: выбор интересов, 8 вопросов входной диагностики и персональная последовательность предметов;
- Главная, Задания, Темы, AI-чат, Атоммаркет и Кабинет;
- теория в формате последовательных флешкарточек;
- учебный каталог хранится в JSON: 50 уроков, 250 флешкарточек и 72 задания;
- у каждой флешкарточки есть ссылка на источник; у заданий хранится источник и признак авторской/FIPI-адаптированной формулировки;
- персональная программа на Главной строится из интересов и результатов входного теста, а сами уроки по-прежнему открываются через раздел «Темы»;
- атомкоины, подсказки, усилители и коллекционные значки;
- АТОМ+ и выдача ключей через Telegram-бота;
- Flask + SQLite;
- интерфейс без emoji: используются SVG-иконки и отдельное изображение атомкоина.

## Учебный контент в JSON

Канонический учебный контент больше не зашит в `backend/app.py`:

- `backend/content/courses/*.json` — предметы, уроки и готовые флешкарточки;
- `backend/content/questions/*.json` — банк заданий;
- `backend/content/manifest.json` — версия и контрольные количества контента.

При старте Flask JSON синхронизируется с SQLite по стабильным `key`. SQLite нужен для ID, прогресса, попыток и аккаунтов; редактировать теорию и вопросы следует именно в JSON. Для новой флешкарточки обязательны `type`, `title`, `text` и `source` с `title`/`url`.

Материалы являются оригинальным учебным пересказом/синтезом с указанием источников. Задания с `origin: "fipi-inspired"` составлены заново по темам и формату открытых банков ФИПИ и содержат прямую ссылку на официальный банк, а не массовую копию условий.

## Мобильные устройства

Интерфейс адаптирован под телефоны и планшеты: безопасные отступы iOS, нижняя навигация, горизонтальные списки предметов без наложения, адаптивные карточки, модальные окна с прокруткой, крупные touch-targets и корректная работа экранной клавиатуры.

## PWA

Добавлены `manifest.webmanifest`, service worker и иконки 192/512. После production-сборки приложение можно устанавливать на поддерживаемых устройствах как отдельное приложение. API-запросы и сессионные данные service worker не кэширует.

Для проверки production/PWA:

```bash
npm install
npm run build
npm run preview
```

## Запуск backend и Telegram-бота

Теперь это один процесс и один набор зависимостей:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
backend/.venv/bin/python backend/app.py
```

Flask API запускается на `http://localhost:5001`. Если задан `TELEGRAM_BOT_TOKEN`, тем же `backend/app.py` автоматически запускается Telegram-бот в отдельном потоке. Он использует ту же SQLite-базу и ту же функцию создания ключей АТОМ+. Если токен не задан, веб-приложение продолжает работать без бота.

Основные переменные:

```bash
FLASK_SECRET_KEY=change-me
TELEGRAM_BOT_TOKEN=
TELEGRAM_ADMIN_IDS=123456789
TELEGRAM_BOT_URL=https://t.me/yasno_sub_bot
DUATOM_APP_URL=http://localhost:8080
OPENAI_API_KEY=
```

Frontend для разработки:

```bash
npm run dev
```

Vite проксирует `/api` на Flask.

## Важно

Это учебный демонстрационный проект и не официальный сервис Госкорпорации «Росатом». Учебные материалы не заменяют официальные документы, инструкции и регламенты атомной отрасли.
